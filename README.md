# quick_songs

Static setlist page for quickly opening song chords.

## GitHub Pages deployment

This repository can be deployed directly to GitHub Pages with the workflow at `.github/workflows/deploy-pages.yml`.

To enable it in GitHub:

1. Open the repository settings.
2. Go to **Pages**.
3. Set **Source** to **GitHub Actions**.
4. Push to `main` or run the workflow manually.

The workflow publishes `index.html` as the site entry point.
